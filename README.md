# P-0660 임대관리 — 미납 독촉 · 내용증명 PDF (RentalNoticeForm)

임대인의 **미납 감지부터 법적 절차 연결까지** 한 화면에서 4단계로 진행하는 입력 폼입니다.
P-0660 임대관리 MVP의 첫 화면이며, 3단계에서 **한글이 깨지지 않는 내용증명 PDF**를 만들어 내려받을 수 있습니다.
비전공자도 그대로 따라 실행하고 확인할 수 있도록 정리했습니다.

---

## 1. 이 프로그램이 하는 일 (한눈에)

화면은 **4단계 진행 표시기**와 단계별 카드로 이루어져 있습니다.

| 단계 | 이름 | 부제 | 하는 일 |
| --- | --- | --- | --- |
| 1단계 | 미납 감지 | D+1 · 미납 정보 입력 | 세입자명·주소·미납 개월수·계좌번호·임대차 유형을 입력받고 검증합니다. |
| 2단계 | 부드러운 독촉 | 카톡 · 문자 고지서 | 입력값으로 **카톡/문자 고지서 문구**를 자동 생성해 보여줍니다. |
| 3단계 | 법적 경고 | 내용증명 PDF 생성 | **내용증명 PDF 다운로드**(한글 폰트 내장)와 화면 미리보기·인쇄를 지원합니다. |
| 4단계 | 법적 절차 | 명도소송 · 지급명령 연결 | 내용증명 발송 → 지급명령 → 명도소송 → 강제집행 순서를 안내합니다. |

### 1-1. 1단계 입력 항목

| 입력 칸 | 필수 | 규칙 |
| --- | --- | --- |
| **세입자명** (예: 홍길동) | 필수 | 비어 있으면 안 됩니다. |
| **주소(소재지)** (예: 경기도 안양시 동안구 평촌대로 214) | 필수 | 비어 있으면 안 됩니다. |
| **미납 개월수** (1 이상의 정수) | 필수 | `1 이상의 정수`. |
| **계좌번호** (숫자 9자리 이상) | 필수 | 하이픈 등 기호는 자동 무시하고 `9자리 이상`. |
| **임대차 유형** (주택 / 상가) | 필수 | 기본값은 **주택**. 유형에 따라 자동 삽입되는 **법령 조항이 달라집니다**. |
| **임대인명** | 선택 | 비워 두면 `임대인`으로 표기됩니다. |
| **임대인 연락처** | 선택 | 비워 두면 표기하지 않습니다. |

검증 규칙: 네 칸(필수 4개) 중 하나라도 비어 있거나 규칙을 어기면 1단계에 머무르며 각 칸 아래에 오류 메시지를 표시합니다.

### 1-2. 자동으로 붙는 법령 근거 (핵심 기능)

미납 개월수와 임대차 유형을 읽어 **법령 조항을 자동으로 골라 넣습니다.**

| 임대차 유형 | 연체 기준 | 충족 시 인용하는 조항 |
| --- | --- | --- |
| 주택 | **2기** 이상 차임 연체 | `「민법」 제640조` (차임 연체를 이유로 한 계약 해지) · 주택임대차보호법 관련 조항 |
| 상가 | **3기** 이상 차임 연체 | `「상가건물 임대차보호법」 제10조의8` (3기 차임 연체 시 계약 해지) · 제10조 제1항 |

- 기준에 **미달**하면(예: 상가인데 2기만 연체) 해지 조항을 쓰지 않고, **지급 최고(催告) 근거 조항**을 대신 넣고
  `"3기의 차임액에 1개월 미달"`처럼 얼마나 모자란지를 문장으로 알려 줍니다.
- 즉 같은 화면이라도 입력값에 따라 문서에 인용되는 법 조항이 달라지고, PDF 문구도 함께 달라집니다.

### 1-3. 내용증명 PDF 규격

| 항목 | 값 |
| --- | --- |
| 용지 | **A4 세로** (210 × 297 mm) |
| 여백 | 위 **20** / 아래 **40 초과 금지(257 mm 이내)** / 좌 **15** / 우 **15** mm |
| 글꼴 | **나눔고딕(NanumGothic)** 을 PDF 안에 직접 심음(임베드) → 어느 PC에서 열어도 한글이 깨지지 않음 |
| 파일 이름 | `내용증명_<임대차유형>_<세입자명>_<작성일 YYYYMMDD>.pdf` (예: `내용증명_주택임대차_홍길동_20261012.pdf`) |

여백 규격은 **우체국 e-그린우편** 업로드 기준(A4 세로, 위 20 / 아래 40 / 좌 15 / 우 15 mm)에 맞춘 것입니다.

## 4. 실행 방법

### 4-1. 개발 서버로 화면 보기

```
npm run dev
```

터미널에 표시되는 주소(보통 `http://localhost:5173`)를 브라우저에서 엽니다.
브라우저 창 폭을 좁혀 보면 모바일 화면(2열 단계 표시)으로 자연스럽게 바뀝니다.

### 4-2. 배포용 빌드 (선택)

```
npm run build
```

성공하면 `dist/` 폴더에 결과물이 생성됩니다. 한글 폰트도 `dist/fonts/NanumGothic-Regular.ttf` 로 함께 복사되므로
빌드 결과물만 서버에 올려도 PDF가 정상 동작합니다.

```
npm run preview
```

npm test

- 실행 결과 예시: `Test Files  5 passed (5)` / `Tests  82 passed (82)`
- 테스트 파일과 검증 내용:

| 파일 | 개수 | 검증 내용 |

> 테스트에서는 `form` 엘리먼트에 직접 `submit` 이벤트를 보냅니다(`submitForm` 헬퍼 참고).
>
> 참고 2: 내용증명 PDF는 2MB 한글 폰트를 심어 만들기 때문에 한 건당 1초 안팎이 걸립니다.
> `vite.config.js` 에 `testTimeout: 30000` 을 설정해 두었습니다(기본 5초로는 부족).

### 5-2. 코드 검사 (lint)

```
npm run lint
```

- **오류 0건**이면 통과입니다(종료 코드 0).
- 현재 `src/components/Calculators.vue` 에 기존 경고 12건이 남아 있습니다(이번 작업에서 건드리지 않은 파일).

### 5-3. 만든 PDF를 제3자 도구로 다시 확인 (선택)

브라우저 없이도 PDF의 한글·규격을 검증할 수 있습니다.

```
# 1) 다른 창에서 개발 서버를 띄운다
npm run dev

# 2) (창을 하나 더 열어) 실제 브라우저와 같은 방식으로 폰트를 내려받아 PDF를 만든다
node scripts/probe_http_font.mjs

# 3) 만들어진 PDF를 pymupdf·fontTools 로 뜯어서 확인한다
python scripts/verify_notice_pdf.py
```

- 기대 결과(마지막 줄): `✅ 검증 통과 — 한글 렌더링·법령 문구·e-그린우편 여백 규격·겹침 없음 모두 확인`
- `verify_notice_pdf.py` 는 다음을 검사합니다.
  1. PDF가 열리는가 · 쪽수
  2. 한글이 **글자로** 추출되는가(폰트가 심어졌는가) — 추출한 한글 음절 수를 출력
  3. 인용해야 할 법령 문구가 실제로 들어 있는가(주택/상가 각각)
  4. e-그린우편 여백 규격(위 20·아래 257·좌 15·우 195 mm)을 지키는가
  5. 글자가 서로 겹치지 않는가
  6. **내용증명을 만드는 코드에 폰트에 없는 글자가 없는가**(한자·기호 누락 사전 차단)

### 5-4. 손으로 확인하는 수동 점검 시나리오

1. `npm run dev` 실행 후 브라우저 접속.
2. 아무것도 입력하지 않고 **미납 감지 시작** 클릭 → 1단계에 그대로 있고, 각 칸 아래에 "…입력해 주세요." 표시.
3. 계좌번호에 `1234`만 입력하고 클릭 → "계좌번호는 9자리 이상이어야 해요." 표시.
4. **임대차 유형**을 `주택`, 미납 개월수를 `3` 으로 채우고 나머지 칸을 올바르게 입력 → **2단계** 이동, 고지서에 입력값 반영.
5. **고지서 확인 · 다음** 클릭 → **3단계** 이동. 아래를 확인한다.
   - 미리보기 제목이 `내 용 증 명` 이고, 발신/수신·미납 기간·연체 요건·계좌번호가 표시된다.
   - `【법령 근거】` 에 `「민법」 제640조` 가 들어 있다.
6. **📥 내용증명 PDF 다운로드** 클릭 → 버튼이 `PDF 생성 중…` 으로 바뀌었다가,
   `내용증명 PDF를 저장했습니다: 내용증명_주택임대차_홍길동_20261012.pdf` 안내가 뜨고 파일이 내려받힌다.
7. 내려받은 PDF를 열어 **한글이 네모(□)로 깨지지 않는지**, A4 세로인지 확인한다.
8. 1단계로 돌아가(또는 처음부터) **임대차 유형을 `상가`, 미납 개월수를 `3`** 으로 바꾸고 3단계까지 진행
   → `【법령 근거】` 에 `「상가건물 임대차보호법」 제10조의8` 이 들어 있는지 확인한다. (§1-2 표와 대조)
9. 미납 개월수를 `1` 로 낮춰 다시 3단계까지 진행 → 해지 조항 대신 **지급 최고 근거**와
   `"…개월 미달"` 문구가 나오는지 확인한다.
10. **법적 절차 연결** 클릭 → **4단계** 이동, 절차 목록 표시. **새로 시작** 클릭 → 모든 입력과 단계가 초기화.

> PDF 다운로드가 실패하면 화면에 `PDF 생성에 실패했습니다: <원인>` 이 표시됩니다.
> 가장 흔한 원인은 폰트 파일 누락입니다 — `public/fonts/NanumGothic-Regular.ttf` 가 있는지 확인하세요.

## 7. 기술 선택 이유 (요약)

- **Vue 3 (`<script setup>`)** — 상태(단계·입력값)와 화면을 한 파일에서 다루기 쉬워 입력 폼 구현에 적합합니다.
- **Vite** — 설치·실행이 빠르고 설정이 단순합니다.
- **jsPDF 4.2.1** — 브라우저에서 PDF를 직접 만듭니다. **서버가 필요 없어** 임대인 PC에서 바로 저장됩니다.
  무료 내장 폰트로는 한글을 그리지 못하므로, **나눔고딕 TTF를 PDF 안에 심어** 어디서 열어도 깨지지 않게 했습니다.
- **법령 엔진을 화면에서 분리(`legalEngine.js`)** — 조항·문구 규칙을 순수 함수로 두어 화면(HTML)·PDF·테스트가
  **같은 문구**를 쓰도록 했습니다. 조항이 바뀌면 이 파일 한 곳만 고치면 됩니다.
- **Vitest + @vue/test-utils + jsdom** — `.vue` 컴포넌트를 브라우저 없이 실제로 마운트해 상호작용(입력·제출·버튼)까지 검증합니다.
- **ESLint 9 (flat config) + eslint-plugin-vue** — Vue 문법까지 검사합니다.

## 8. 주의 사항

- 본 화면은 **입력 안내 목적의 예시 화면**입니다. 실제 법적 조치(내용증명 발송, 지급명령, 명도소송 등)는 자격 있는 법률 전문가의 자문을 받아야 합니다.
- 자동 삽입되는 법령 조항은 **연체 개월수와 임대차 유형만으로 고른 결과**입니다. 실제 사안의 특약·계약기간·갱신 여부 등은 반영하지 않습니다.
- 나눔고딕은 **SIL Open Font License 1.1** 로 상업적 사용·재배포가 가능합니다. 원본: <https://github.com/google/fonts/tree/main/ofl/nanumgothic>
- 나눔고딕에는 **한자·일부 기호 글리프가 없습니다**. 폰트에 없는 글자를 쓰면 PDF에서 그 글자만 소리 없이 사라지므로,
  `tests/noticeFontCoverage.spec.js` 와 `scripts/verify_notice_pdf.py` 가 이를 사전에 차단합니다.
  내용증명 문구에 새 글자를 추가할 때는 **반드시 테스트를 다시 돌리세요.**
- 비밀번호·API 키 등 비밀값은 코드에 넣지 않았습니다. 필요한 환경 변수는 `.env`로 관리하며 `.gitignore`에 등록되어 있습니다.
