# P-0660 임대관리 4단계 입력 폼 (RentalNoticeForm)

임대인의 **미납 감지부터 법적 절차 연결까지** 한 화면에서 4단계로 진행하는 입력 폼입니다.
P-0660 임대관리 MVP의 첫 화면(입력 담당 컴포넌트)으로, 비전공자도 그대로 따라 실행하고 확인할 수 있도록 정리했습니다.

---

## 1. 이 프로그램이 하는 일 (한눈에)

화면은 **4단계 진행 표시기**와 단계별 카드로 이루어져 있습니다.

| 단계 | 이름 | 부제 | 하는 일 |
| --- | --- | --- | --- |
| 1단계 | 미납 감지 | D+1 · 미납 정보 입력 | 세입자명·주소·미납 개월수·계좌번호를 입력받고 검증합니다. |
| 2단계 | 부드러운 독촉 | 카톡 · 문자 고지서 | 입력값으로 **카톡/문자 고지서 문구**를 자동 생성해 보여줍니다. |
| 3단계 | 법적 경고 | 내용증명 PDF 생성 | 발송용 **내용증명** 미리보기를 만들고 인쇄/PDF 저장을 지원합니다. |
| 4단계 | 법적 절차 | 명도소송 · 지급명령 연결 | 내용증명 발송 → 지급명령 → 명도소송 → 강제집행 순서를 안내합니다. |

입력 필드(1단계)는 요구사항 그대로 다음 4개입니다.

1. **세입자명** (예: 홍길동)
2. **주소(소재지)** (예: 경기도 안양시 동안구 평촌대로 214)
3. **미납 개월수** (1 이상의 정수)
4. **계좌번호** (숫자 9자리 이상)

검증 규칙:

- 네 칸 중 하나라도 비어 있으면 1단계에 머무르며 각 칸 아래에 오류 메시지를 표시합니다.
- 미납 개월수는 `1 이상의 정수`여야 합니다.
- 계좌번호는 `숫자 9자리 이상`이어야 합니다(하이픈 등 기호는 자동 무시).

## 4. 실행 방법

### 4-1. 개발 서버로 화면 보기

```
npm run dev
```

터미널에 표시되는 주소(보통 `http://localhost:5173`)를 브라우저에서 엽니다.
브라우저 창 폭을 좁혀 보면 모바일 화면(2열 단계 표시)으로 자연스럽게 바뀌는 것을 확인할 수 있습니다.

### 4-2. 배포용 빌드 (선택)

```
npm run build
```

성공하면 `dist/` 폴더에 결과물이 생성됩니다.

```
npm run preview
```

## 5. 테스트 방법 (검증 담당자용)

### 5-1. 단위 테스트 (자동)

```
npm test
```

- 실행 결과 예시: `Tests  5 passed (5)`
- 테스트 파일: `tests/RentalNoticeForm.spec.js`
- 검증 항목(5개):
  1. 초기 상태에서 1단계가 활성화되고 4개 입력 필드가 비어 있다.
  2. 4단계 진행 표시기가 `미납 감지 / 부드러운 독촉 / 법적 경고 / 법적 절차`를 모두 보여준다.
  3. 미입력 상태로 제출하면 1단계에 머무르며 오류 메시지가 표시된다.
  4. 모든 필드를 입력하고 제출하면 2단계로 진행하며 고지서에 입력값이 반영된다.
  5. 계좌번호가 9자리 미만이면 검증에 실패하고 1단계에 머무른다.

> 참고: 테스트는 jsdom에서 실행됩니다. jsdom은 `submit` 버튼 클릭만으로는 폼의 `submit` 이벤트를 발생시키지 않으므로, 테스트에서는 `form` 엘리먼트에 직접 `submit` 이벤트를 보냅니다(`submitForm` 헬퍼 참고).

### 5-2. 코드 검사 (lint)

```
npm run lint
```

- 오류 0건, 경고 0건이면 통과입니다(종료 코드 0).

### 5-3. 손으로 확인하는 수동 점검 시나리오

1. `npm run dev` 실행 후 브라우저 접속.
2. 아무것도 입력하지 않고 **미납 감지 시작** 클릭 → 1단계에 그대로 있고, 각 칸 아래에 "…입력해 주세요." 표시.
3. 계좌번호에 `1234`만 입력하고 클릭 → "계좌번호는 9자리 이상이어야 해요." 표시.
4. 네 칸을 모두 올바르게 입력하고 클릭 → **2단계(필수 고지)**로 이동, 세입자명·미납 개월수·계좌번호가 고지서/요약에 표시.
5. **고지서 확인 · 다음** 클릭 → **3단계(내용증명)** 이동, 인쇄/PDF 저장 버튼 동작.
6. **법적 절차 연결** 클릭 → **4단계(법적 절차)** 이동, 4단계 절차 목록 표시.
7. **새로 시작** 클릭 → 모든 입력과 단계가 초기화.

## 7. 기술 선택 이유 (요약)

- **Vue 3 (`<script setup>`)** — 상태(단계·입력값)와 화면을 한 파일에서 다루기 쉬워 입력 폼 구현에 적합합니다.
- **Vite** — 설치·실행이 빠르고 설정이 단순합니다.
- **Vitest + @vue/test-utils + jsdom** — `.vue` 컴포넌트를 브라우저 없이 실제로 마운트해 상호작용(입력·제출)까지 검증할 수 있습니다.
- **ESLint 9 (flat config) + eslint-plugin-vue** — Vue 문법까지 검사합니다.
